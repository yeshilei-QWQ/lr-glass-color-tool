## 最新版本（V2-lite）

> `/desktop` — 精简版，详见 [desktop/README](./desktop/README.md)

V1 是约 64KB 的单文件（两个 `<script>` 块相互覆盖），V1.5 拆分为 **HTML + 10 个 JS 模块**，为后续扩展与 Electron 封装打好结构基础。

**模块划分：**
```
v1.5/
├── index.html          主页面（HTML / CSS / DOM）
└── src/
    ├── state.js        全局状态、常量、默认参数
    ├── history.js      历史 / 撤销 / 重做
    ├── controls.js     滑块、参数同步、分组重置、图片导入
    ├── view.js         画布、视图模式、对比分割线
    ├── color.js        色彩空间与主调色算法
    ├── blend.js        混合模式
    ├── layers.js       图层系统与图层面板
    ├── blur.js         高斯模糊
    ├── adjust.js       图层渲染管线与导出
    └── app.js          工具、预设、API、初始化
```

**拆分原则：** 按职责分文件、保持原加载顺序（覆盖关系与 V1 一致）、零逻辑改动。

**已知待优化（V2）：**
- 滑块拖动卡顿（逐像素实时运算 + 渲染）
- 滑块不支持直接数值输入
- 封装 Electron 桌面应用

**使用：** 双击打开 `v1.5/index.html`（需保持 `src/` 目录同级）。

## 通用功能特性

### 调色面板
- **基础调整**：曝光、对比度、高光、阴影、白色色阶、黑色色阶
- **白平衡**：色温、色调
- **颜色**：饱和度、自然饱和度
- **效果**：清晰度、颗粒、暗角
- **HSL 通道**：红 / 绿 / 蓝 三通道的色相、饱和度、明度

### 图层系统
- 多图层叠加、独立参数
- 混合模式：正常 / 正片叠底 / 滤色 / 叠加 / 柔光 / 强光 / 变暗 / 变亮 / 差值 / 排除
- 不透明度、启用、重命名、删除、高斯模糊

### 其他
- 对比视图（原图 / 调整 / 分割对比）
- 历史记录与撤销重做（Ctrl+Z / Ctrl+Y）
- 预设保存（标签 / 搜索 / 筛选）
- API JSON 参数接入（本地 / 远端）
- 直方图、导出 PNG、拖拽导入
