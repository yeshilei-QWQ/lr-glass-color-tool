# LR Glass 调色工具

一个纯前端、零依赖的 Lightroom 风格图片调色工具。打开即用，所有数据保存在浏览器本地。

> **作者：X1a0ye**

---


## 版本规划（迭代思路 · 备忘）

> **当前主线：`lite` 轻量精简版，单线持续迭代，将来功能齐全后去掉 `-lite` 转正。**

### 命名规则
| 变更类型 | 版本示例 | 说明 |
| --- | --- | --- |
| 小优化 / 功能增量 | `V2.1-lite` → `V2.2-lite` … | 次版本号 +1，末尾保留 `-lite` |
| 大重构 / 里程碑 | `V3-lite` → `V4-lite` | 主版本号 +1 |
| 转正（功能齐全成熟后） | `V4.0` / `V5.0` | **去掉 `-lite` 后缀**，转为正式版号 |

## 最新版本（V2.2-lite）

> V2.2-lite —— Electron 桌面版，详见 [desktop/README](./desktop/README.md)

- **预览缩放**：新增缩放工具条（放大 / 缩小 / 适应窗口 / 100%），自由调整预览大小
- **直方图增强**：从单亮度升级为「亮度 + RGB 三通道」，支持 Lum / RGB / R / G / B 五种显示切换
- **长按看原图**：「调整」视图下按住预览区临时显示原图，松开即恢复（Lightroom 经典交互）
- 运行：源码 `desktop` 目录执行 `npm start`，或直接使用 `/desktop/dist` 下的 `LR Glass 2.2.0-lite.exe` Windows 便携版

## 通用功能特性

### 调色面板
- **基础调整**：曝光、对比度、高光、阴影、白色色阶、黑色色阶
- **白平衡**：色温、色调
- **颜色**：饱和度、自然饱和度
- **效果**：清晰度、颗粒、暗角
- **HSL 通道**：红 / 绿 / 蓝 三通道的色相、饱和度、明度

### 图层系统
- 多图层叠加、独立参数
- 混合模式：正常 / 正片叠底 / 滤色 / 叠加 / 柔光 / 强光 / 变暗 / 变亮 / 差值 / 排除
- 不透明度、启用、重命名、删除、高斯模糊

### 其他
- 对比视图（原图 / 调整 / 分割对比）
- 历史记录与撤销重做（Ctrl+Z / Ctrl+Y）
- 预设保存（标签 / 搜索 / 筛选）
- API JSON 参数接��（本地 / 远端）
- 直方图、导出 PNG、拖拽导入
