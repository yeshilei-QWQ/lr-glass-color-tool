# LR Glass 调色工具

一个纯前端、零依赖的 Lightroom 风格图片调色工具。打开即用，所有数据保存在浏览器本地。

> **版本：V1 · by X1a0ye**

---

## 功能特性

### 调色面板
- **基础调整**：曝光、对比度、高光、阴影、白色色阶、黑色色阶
- **白平衡**：色温、色调
- **颜色**：饱和度、自然饱和度
- **效果**：清晰度、颗粒、暗角
- **HSL 通道**：红 / 绿 / 蓝 三通道各自的色相、饱和度、明度

### 图层系统
- 多图层叠加，每层独立调整参数
- 混合模式：正常、正片叠底、滤色、叠加、柔光、强光、变暗、变亮、差值、排除
- 图层不透明度调节、启用 / 禁用、重命名、删除
- 高斯模糊滤镜（每层可单独设置）

### 对比查看
- 三种视图模式：**原图 / 调整 / 对比（分割线可拖动）**
- 分割线位置可重置

### 历史记录
- 撤销 / 重做（支持快捷键 Ctrl+Z / Ctrl+Y / Ctrl+Shift+Z）
- 步骤列表可视化，可点击跳转到任意历史步骤
- 历史记录完整保存图层结构与参数（不止当前参数）

### 预设管理
- 保存当前调整为一键预设，支持标签分类、搜索、筛选
- 预设持久化保存在浏览器 localStorage

### API 接入
- 粘贴 JSON 参数直接应用（键名对应滑块 id）
- 支持从远端 URL 拉取配置参数

### 其他
- 直方图实时显示
- 图片信息显示（尺寸）
- 拖拽 / 点击导入图片
- 导出调整后 PNG
- 磨砂玻璃（Glass）iOS 风格 UI

---

## 使用说明

1. 用浏览器直接打开 `lr-color-tool.html`（无需安装任何依赖）
2. 点击「打开图片」或直接拖拽图片到窗口
3. 拖动滑块调色，松开滑块自动记录一步历史
4. 点击「对比」模式拖动分割线，查看原图 / 调整效果
5. 满意后点击「导出图片」保存 PNG

### 快捷键
| 按键 | 功能 |
| --- | --- |
| Ctrl+Z | 撤销 |
| Ctrl+Y / Ctrl+Shift+Z | 重做 |

## 版本历史

### V1（by X1a0ye）
首个完整版本，包含以上全部功能。

**V1 已修复的问题：**
- 导入大图时 `putImageData` 尺寸不匹配导致的 `IndexSizeError` 崩溃
  - 原因：渲染前画布尺寸未初始化（仍为默认 300×150），导致写入超出画布范围
  - 修复：导入流程改为「先初始化画布尺寸，再触发渲染」
- 对比度算法错误导致轻微曝光就严重过曝
  - 原因：对比度公式在滑块为 0 时系数竟为 64.75（应为 1），所有像素被剧烈拉伸
  - 修复：改为正确的线性对比度公式 `(r - 128) * (1 + contrast/100) + 128`
- 撤销 / 重做与图层结构脱节
  - 原因：历史只保存当前 `params`，恢复时图层数据丢失
  - 修复：历史快照完整保存 `layers` 与 `activeLayerIndex`，恢复时重建图层结构
- 多次加载图片后分割线拖动失效
  - 原因：`addEventListener` 重复绑定，旧闭包引用已失效的画布元素
  - 修复：提取独立处理函数，绑定前先 `removeEventListener`
- 未导入图片时点击「重置全部」报错
  - 修复：增加 `sourceData` 空值守卫，提示「请先打开图片」
- 导出图片导出的是原图而非调整结果
  - 原因：导出逻辑受视图模式影响
  - 修复：导出时始终走调整渲染管线

## 制作思路

### 技术选型
- **纯原生 JavaScript + HTML5 Canvas**，零第三方依赖，双击即用
- 数据持久化使用浏览器 `localStorage`，无需后端
- UI 采用 iOS 磨砂玻璃（Glassmorphism）风格，符合 Lightroom 深色工作流审美

### 渲染管线
```
导入图片 → 缩放到上限 2048px → 转为 ImageData 源数据(sourceData)
        ↓
渲染时：逐图层 copy 一份 sourceData → applyLayer(该层参数) → 按混合模式合成
        ↓
输出到主画布 → 更新直方图
```
- 单图层时走轻量路径（直接 `applyLayer` 当前参数）
- 多图层时走 `renderComposite` 合成管线，支持混合模式与不透明度
### 色彩算法要点
- **曝光**：`× 2^exposure`（光圈级数语义）
- **对比度**：以 128 为中性点做线性拉伸（修复后公式，滑块 0 时无效果）
- **白平衡**：色温 ±R/B，色调 ±G（带加权系数）
- **HSL 通道**：将 RGB 转到 HSL，按像素主色相区间加权（红色 0° / 绿色 120° / 蓝色 240° 为中心，跨度 50°），模拟 Lightroom 的 HSL 分区调整
- **颗粒**：确定性伪随机噪声（sin 种子），同一参数下结果可复现
- **暗角**：基于像素到中心距离的径向衰减

### 历史系统设计
- 每次滑块 `change`（松开）记录一步，拖动中不记录，兼顾流畅与可撤销粒度
- 快照采用深拷贝（`JSON.parse(JSON.stringify(...))`），上限 200 步
- 恢复时若快照含图层数据则重建图层，否则回退兼容旧格式

### 已知可优化方向（后续版本）
- 滑块数值直接输入（像 Lightroom 一样键入精确参数）
- 像素级性能优化（当前逐像素运算，大图可能卡顿；可考虑 Web Worker / 预分块）
- 对比度 / 高光 / 阴影算法的 Lightroom 更精确近似
- 预设导出 / 导入（分享给他人）
- 多语言支持
